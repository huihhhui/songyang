# 巫通儿：松阳寻踪

这是 v2 制作仓库。旧 WASD Demo 已弃用，当前产品是由地方物件观察调研小队的互动数字田野档案。

## 开始前

1. 阅读 `docs/v2/`，以其中规范为唯一设计依据。
2. 运行 `Setup-V2.cmd` 安装依赖。
3. 运行 `Start-V2.cmd`，浏览器访问 `http://127.0.0.1:5173/`。

原始角色模型与 Blender 工程位于 `source-assets/character/wutonger/`；v2 风格探索图位于 `references/visual/explorations/`。这些是制作输入，不直接作为公开网页资源。
