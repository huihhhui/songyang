# 游戏美术参考研究｜杨家堂 v2 下一轮方向

## 这轮研究的判断

当前四张方案的核心问题不是“够不够像画”，而是它们把古树、房屋、石阶、纸带都等权摆进正面画幅：没有镜头任务、没有明暗主次，也没有能够记住的空间切口。下一轮不应继续强化纹理或纸张，而应先重建**构图、层级与可玩镜头**。

## 参考对象与可借鉴部分

| 参考 | 借鉴什么 | 不借鉴什么 |
| --- | --- | --- |
| 《The Last Campfire》 | 小尺度场景的舞台光、前中后景层次、单一视觉焦点 | 可爱角色比例、奇幻物件、饱和荧光 |
| 《Harold Halibut》 | 手工实体模型的材料不完美、真实边缘与道具尺度 | 定格人偶感、室内复古科幻 |
| 《SEASON: A letter to the future》 | 田野记录的安静镜头、色彩脚本、远景压低而非堆细节 | 开阔旅行风景和大面积天空 |
| 《Dordogne》 | 手绘媒介的笔触控制、记忆与资料层的切换 | 全画面水彩晕染与甜美亮色 |
| 《The Legend of Tianding》 | 强轮廓、画面分区和视觉叙事的节奏 | 都市漫画感、过强的黑线密度 |

## 推荐的新合成方向：**“实体微缩 × 绘画切景”**

外层总览维持立体微缩模型，但向《The Last Campfire》借“舞台光”和向《Harold Halibut》借“真实手作物感”：

- 相机保持 3/4 俯视，不做地图鸟瞰；只展示一段被裁切的村落坡面。
- 夫妻树不是模型中心的对称摆件：主树压在前景左侧，次树退入右后；屋檐从主树后方切进画面。
- 材质保留现实：夯土黄、旧瓦灰、深樟绿、冷灰石阶；不做糖果色低模。
- 档案 UI 退出画幅边缘，只保留少量可操作的纸签。不要大面积空白纸带。

内层交互改为绘画化“切景”，向《SEASON》借色彩主次、向《Dordogne》借笔触媒介、向《Tianding》借镜头分区：

- 采用**侧前方近景**而非正面全景：主树根从左下切入，石阶斜向进入中景，次树只给树干与一段树冠。
- 主树根、一个屋檐转角、石阶水沟三者构成三角关系；其余村屋压入暗部。
- 不把 UI 纸带放在画内：对话与田野旁注在点击后从边缘覆盖，舞台镜头保持完整。
- 画面使用不透明水粉 / 矿物色块 + 局部墨线；石阶、土墙、瓦片只在焦点区给细节。
- 动效是树影、风过叶层、水沟反光、远处瓦檐的小幅视差，不用全景漂浮或翻页特效。

## 下一轮应避免

1. 对称的两棵“大树 + 两侧房屋”正面陈列。
2. 整张画面平铺树皮、瓦片、纸纹，使所有区域同样清晰。
3. 为了像“档案”而长期占用底部 20–30% 的空白纸带。
4. 低多边形叶片团、塑料感瓦片、随机泛黄纸张和 AI 伪手账笔触。
5. 直接模仿任何参考作品的角色、标志、场景或素材；只借构图与媒介方法。

## 可确认的制作路线

**推荐：路线 P｜低饱和重彩切景**

将外层微缩模型保留为克制的半写实实体模型；内层树根舞台改为低饱和矿物水粉的侧前方切景，UI 独立覆盖。它比当前 A–D 更强调镜头叙事，也比水彩 / 木刻更适合杨家堂的土、瓦、石、树材料。
