# 杨家堂 v2 风格化修订

## 修订目标

将第一版的摄影写实和高密度真实渲染，改为可由 WebGL 实现的手作低面数、纸艺标本和哑光贴图语言。保留纸质档案的整体组织方式，但让每张图的建筑、树、石阶直接服从杨家堂实拍的形态。

## 元素锚点

- 全景屋顶：`D:\codex_sy\sucai\28，27，50N 119，32，34E\1.jpg` — 紧密叠压的灰瓦屋面、坡地与背后植被。
- 夫妻树：`D:\codex_sy\sucai\28，27，50N 119，32，34E\3.jpg` — 双树并置、粗大的根盘、屋檐与石阶贴近树干。
- 石阶及水沟：`D:\codex_sy\sucai\28，27，49N 119，32，32E\6.jpg` — 不规则冷灰石块、湿石缝、墙边狭窄水沟。
- 柴房：`D:\codex_sy\sucai\28，27，49N 119，32，32E\1.jpg` — 夯土黄墙、旧木架、低矮压瓦屋顶、柴枝堆置。

## 修订规则

1. 建筑、树、石阶不再使用摄影级材质与景深；改为明确可读的低面数轮廓、手绘颗粒贴图与哑光块面。
2. 以真实素材的结构为优先：紧密屋顶、双树根盘、贴树屋檐、湿石阶与水沟必须可识别。
3. 仍使用夯土黄、旧瓦灰、樟树深绿、冷灰石阶；不出现白墙泛江南、霓虹、跑图 UI 或虚构文字。
4. 纸张、照片框、卡片均保持无字，真实中文仅在后续网页数据层加入。
