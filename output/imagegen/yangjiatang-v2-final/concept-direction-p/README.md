# 路线 P｜低饱和重彩切景

## 最终推荐

`01_tree-root_painterly-cutscene_v2.png`

以被裁切的主树根占据左前景，石阶与水沟斜向上行；夯土墙和旧瓦檐形成窄巷，次树退到中后景。画面采用矿物水粉与粗粝笔刷，而不是写实树皮或全景村落陈列；底部仅保留极窄深色安全区，UI 在交互时另层覆盖。

## v1 与 v2

- `v1`：构图正确，但树皮和瓦片仍接近写实环境渲染。
- `v2`：针对媒介感重做为低饱和重彩水粉；建议作为后续观察站实现参考。

## 网页落地

- 固定 2.5D 相机；根、墙、瓦檐、石阶、水沟拆为 5–7 个分层贴片或简化 Mesh。
- 视觉焦点区（主根、石阶）用高分辨率手绘贴图，背景墙和次树降低细节与对比。
- 动效只保留树影、叶层微移与水沟反光；文字 / 旁注从 DOM 覆盖层进入，不嵌入画面。

生成方式：项目隔离 API，经 bundled `image_gen.py` 的 `gpt-image-2` 生成。提示词保留在本任务终端记录中；材料锚点为杨家堂夫妻树、石阶水沟、夯土房屋与旧瓦的本地实拍。
