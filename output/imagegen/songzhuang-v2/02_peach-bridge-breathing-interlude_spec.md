# 松庄：石拱桥下的溪中桃子

## 场景定位

这是浏览节奏中的“呼吸段”，不是信息密度高的观察站，也不是完整村落导览。用户进入后先看水、听水、发现卡在石缝里的桃子；调研成员撩水的动作只留下一个轻微涟漪和小范围水花。

## 事实边界

- 溪中桃子与分流石：`D:\\codex_sy\\sucai\\28，27，5N 119，34，11E\\9.jpg`
- 石拱桥与水边石路：`D:\\codex_sy\\sucai\\28，27，8N 119，34，13E\\10.jpg`
- 田野记录说明了“调研人员在旁边石路上用手撩起水嬉戏”。

桃子溪流和石拱桥来自不同记录照片。因此所有合成画面标记为 `creative-reconstruction`：以真实材料构成叙事场景，不声称是一张原始现场的复原。

## 画面层级

1. 主体：画面下三分之一的浅水和石缝；一个桃子是唯一高明度暖色焦点，另有一至两个半淹没的桃子。
2. 空间：石拱桥只占上方约四分之一，作为阴凉的弧形框景；不要增加墙、瓦檐、房屋或满屏植物。
3. 人物：两名不具身份特征的调研成员只以局部手臂、裤脚和水边剪影出现。人物不是主角，不给正脸，不可识别。
4. 留白：至少 45% 是安静的浅水与桥下阴影，供页面呼吸，不放信息面板。

## 视觉语言

- 风格：手作微缩环境，简化而有重量的石块，手绘水粉式表面变化，非摄影化的环境光。
- 体块：石拱桥、石阶、石缝和桃子有清晰的大形，避免高清摄影细节和镜头景深。
- 材质：湿冷灰石、微苔、半透明浅青水、桥洞内的墨绿阴影、桃子的柔和杏粉与橘红。
- 人物：小尺度、低细节、服装为灰蓝和土色；不使用奇幻角色、卡通脸或游戏战斗姿势。

## 色板

- 溪水：`#6D877B` / `#A6B7A3`
- 湿石与桥：`#555A55` / `#808278`
- 桥洞阴影：`#29312C`
- 桃子：`#D48B68` / `#F0B07A`
- 阳光石阶：`#B6A58A`

## 交互与动效

- 默认只有水声、缓慢水纹、桥洞中的明暗呼吸。
- 指针或触摸接近桃子时，桃子只轻轻在石缝中摆动；水纹向外扩散。
- 调研成员的撩水动作 12–16 秒一次，时长小于 0.8 秒，不循环表演式动作。
- 叙事只在用户停留或点触桃子后出现一条短句；证据、出处和更多说明放入二级展开，不覆盖画面。

## 网页实现

- 场景视觉：一张无 UI 定帧作为最终美术目标。
- 前景水面、桃子、桥洞阴影和人物手臂分别拆层，实现 2.5D 小幅动效。
- 文字、导航、证据卡全部为 DOM；不生成进图片。
- 移动端保留桃子和桥洞，弱化人物动作和背景细节。

## 验收标准

- 第一眼读到“桃子被石缝卡住”，第二眼才看到桥和撩水动作。
- 石拱桥是空间框景，不是建筑展示对象。
- 画面安静、留白充足，不能变成古村落旅游海报或任务界面。
- 不包含墙面堆砌、完整房屋、瀑布、虚构文字、霓虹、角色化桃子或 glossy CGI。
