## 构图

镜头低于岸边、贴近水面。前景是安静浅水；中部一条由圆钝石块组成的分流带，桃子被石块拦住；左后方是少量下水石阶；上沿由叶影压住，远处只留一个旧屋檐或斑驳墙面切片。画面不还原整个村落，不放完整民居群，不放人物。

## 色板与材质

- 溪水：青绿、褐绿反光，局部白色水花。
- 石头：冷灰、褐灰、湿黑边；苔藓为低饱和绿。
- 桃子：柔和杏黄、橙粉，是唯一小面积暖色焦点。
- 建筑残片：斑驳灰白与被雨水染暗的土色；旧瓦灰，藤蔓深绿。

松庄可以保留斑驳白灰，但不可渲染成干净白墙旅游村。

## 动态

水线贴石分两路；桃子在水流顶推下轻微晃动但不漂走；叶影在浅水上移动；苔藓和草叶只作极轻的风动。观察者若启用，仅为桃子表面一闪而过的高光或极小眼神，不加卡通肢体。

- R3F 以 5 层实现：前景水面、分流石、桃子、后景石阶／墙檐、叶影遮罩。
