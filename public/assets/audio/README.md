# 声音素材清单

当前已接入：

- `main1.mp3`：全局背景声，首次用户手势后播放，低音量循环。
- `线滑动.mp3`：板桥竹片拖动、纱线摩擦，拖动时循环。
- `线被挑起.mp3`：竹片挑线进入下一阶段时触发一次。
- `垃圾破碎.mp3`：拖出垃圾/碎屑时触发一次。
- `按钮.mp3`：Next、继续、预设切换等明确 UI 操作。
- `滑条.mp3`：数字实验室参数滑动时循环播放。

后续页面的临时素材槽位（文件名确定后可直接替换，不需要改组件代码）：

- `flower-rope-ambience.mp3`：花链条页面风声/绳索环境。
- `flower-rope-drag.wav`：拖动花朵时的绳结轻响。
- `paper-stage-ambience.mp3`：首页室内空间底噪。
- `lamp-pull.wav`：灯绳摩擦与灯亮提示。
- `clay-crumble.wav`：陶土碎屑滑落。
- `ceramic-clink.wav`：陶片轻碰。
- `bee-ambience.mp3`：蜂房低声嗡鸣。
- `bee-wing.wav`：蜜蜂飞出短音效。
- `preset-switch.wav`：3D 预设切换短音效。

音效建议保持短、低动态，环境声建议压到约 `-18 LUFS`，交互音效约 `-12 LUFS`，避免盖住页面文字和视频。
