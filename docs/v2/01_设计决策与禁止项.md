# 设计决策与禁止项

## 已冻结决策

| 领域 | 决策 |
| --- | --- |
| 叙事主体 | 地方物件观察调研小队；巫通儿仅作彩蛋，档案界面承担归档 |
| 内容形态 | 知识卡片、视觉小说对话、现场趣事、数字标本实验室并存 |
| 空间结构 | 村落章节由独立观察站组成，不还原完整地理布局，不要求跑图 |
| 视觉方向 | 田野图鉴、民艺标本、实拍证据层与低多边形空间拼贴 |
| 重点展示 | 重要物件采用卡片内预览与站内全屏实验室两级呈现 |
| 数据伦理 | 事实、引用、肖像、声音、姓名、对话必须记录来源或授权状态 |

## 非目标

- 不制作战斗、数值成长、收集货币或强制任务。
- 不以素材不足的卫星图或零散照片推断、宣称还原村落整体布局。
- 不把所有地点写成巫通儿独白。
- 不将未经核验的传说、树龄、历史或采访内容写成事实。
- 不用低质量单张照片伪造完整点云、精确扫描或高精度文保建模。
- 不以浏览器新窗口承载实验室，优先使用站内路由并保留返回上下文。

## 内容证据状态

| 值 | 含义 | 能否直接面向观众展示 |
| --- | --- | --- |
| `field-note` | 调研者亲历观察 | 可以，需使用观察性措辞 |
| `oral-account` | 现场由具体讲述者口述、由成员整理 | 可以，须标明讲述者与整理者，不扩大为普遍事实 |
| `onsite-exhibit` | 现场展板、馆内说明等可追溯的陈列内容 | 可以，须附照片编号或展板来源，不代替独立史实考证 |
| `public-source` | 可追溯公开资料 | 可以，需保留出处 |
| `creative` | 基于素材的创作化片段 | 可以，必须标明创作化 |
| `pending` | 尚未核验或授权 | 不可作为正式内容 |

## 人物、对话与文化素材（已确认）

- 店主、村民、调研成员、畲歌老师均以风格化重绘形象出现，不使用真人正脸作为角色立绘。
- 调研小队作为共同在场者出现，不默认由任一成员代言。首发不展示真实姓名；成员笔记使用稳定作者 ID 与可替换的展示署名。
- 没有录音，首发不制作语音播放、配音采访或拟真音频。
- 店主/村民相关文本根据作者回忆与感悟创作，必须标记为 `field-note` 或 `creative`，不得加引号伪装为逐字原话，也不得标注为受访者直接引语。
- 畲族老师、头饰、布带的人物叙事与文化说明以调研小队记录为基础。兰老师的婚嫁、布带和抹灰内容允许作为 `oral-account` 公开转述，标明“兰老师现场讲述，调研小队整理，辉记录”；未核验的文化含义不得写成跨地区、跨群体的确定事实。
- 实拍照片可作为证据层增加可信度，但涉及可识别人物时须裁切、遮挡或取得明确公开许可；头饰和布带实拍图同样须确认拍摄及公开范围。

## 语言与命名（已确认）

- 全站以中文为主。
- 板桥畲族乡可在章节标题、纹样边框、索引标签等非关键阅读位置加入畲族语言文字作为装饰。
- 畲族文字只能使用经来源核验的原词、拼写或转写；不得为装饰自行编造文字。若暂时无法核验，改用抽象纹样，不以文字替代。
- 观察者使用风格化、艺术化命名；数据中仍须保留真实物件名称与原始素材来源，以便核验。
- `hui` 是成员“辉”的作者 ID，不是整个调研小队的代称。后续成员各自使用独立作者 ID；是否显示其署名或形象由成员授权数据控制。
