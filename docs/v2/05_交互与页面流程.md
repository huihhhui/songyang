# 交互与页面流程

## 站内信息架构

```text
可跳过的巫通儿引导开场
  -> 档案总览
  -> 村落章节索引
    -> 独立观察站场景
      -> 知识卡片 / 对话 / 趣事
        -> 数字标本实验室（可选）
```

## 页面状态

| 页面/状态 | 用户目的 | 必备元素 | 退出方式 |
| --- | --- | --- | --- |
| 档案总览 | 选择村落 | 村落名、进度、简短导语、巫通儿引路 | 进入章节 |
| 村落章节 | 选择观察站 | 观察站索引、实拍碎片、返回总览 | 进入观察站/返回 |
| 观察站 | 观看一个短场景 | 观察者、实拍证据、短文本、继续按钮 | 返回章节 |
| 知识卡 | 阅读可核验内容 | 标题、图片、正文、关键词、来源状态 | 收起/转实验室 |
| 对话 | 阅读人与人或物件旁观 | 说话者、授权肖像或剪影、逐句推进 | 返回观察站 |
| 田野旁注 | 阅读某位调研成员的第一人称感想 | 统一风格化小队形象占位、内心独白、`field-note` 来源标记 | 收起/返回来源场景 |
| 趣事 | 阅读轻量现场片段 | 分镜、观察者注释、隐私状态 | 返回观察站 |
| 数字标本实验室 | 观察模型/点云/证据 | 旋转模型、实拍对照、数字化状态、来源 | 返回原观察站 |

观察站的阅读优先级为：人际对话、现场观察、调研成员感悟与趣事优先；观察者只负责把注意力带入这些内容。只有需要准确解释的文化材料、展板内容或数字标本，才以资料卡作为该站主要阅读内容。

## 控制规则

- 鼠标/触摸点击是主操作，键盘只作为辅助；不提供 WASD 漫游。
- 所有内容必须有可见的返回与关闭入口。
- 对话可逐句推进，也可一次显示完整段落；不得自动消失。
- “田野旁注”不等同于人物采访或知识卡：它使用内心独白样式，明确标记作者或“调研小队成员”，可被跳过且不能是理解事实内容的唯一渠道。不同成员的旁注按作者分别呈现，不合并成小队统一结论。
- 每个观察站是独立舞台化场景，不声称其与其他观察站存在精确可走的地理连接。
- 引导开场不超过 10 秒，不依赖语音；结束后进入可自由选择的村落档案索引。
- 开场采用“档案篝火夜话”：来自不同村落的观察者围在篝火意象旁，谈论最近到访的一群“怪人”（调研组）。它是跨村落的创作化叙事框架，不声称是三个村落真实发生于同一时空的事件。
- 全站提供可见的静音/音量控制；配乐与环境音不能是完成理解内容的唯一渠道。
- 独立观察站采用固定构图的 2.5D 舞台；只使用轻微视差、环境动效与镜头切换，不提供自由环视或自由移动。数字标本实验室单独支持模型旋转。
- 观察者不得占据长篇文本、连续对白或场景结论的位置。它可以在开场、转场和趣事注释中出现，但不替代人与人的对话、调研者的第一人称旁注或证据材料。
- 完成观察站后，在村落档案索引留下非强制的已阅印记或纸签；观众可随时重看，不设置收集数值、强制顺序或解锁门槛。

## 数字标本实验室

使用站内路由 `/archive/:id`。进入前在知识卡内展示预览；进入后提供“模型”“实拍对照”“点云/数字化状态”分区。没有扫描数据时，隐藏点云操作而显示数据不足说明。
