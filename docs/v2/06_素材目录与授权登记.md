## 使用分级

| 等级 | 允许用途 | 条件 |
| --- | --- | --- |
| A | 公开展览、页面主图、数字标本对照 | 版权与人物/店铺许可完整 |
| B | 小尺寸证据图、内部评审 | 有拍摄权但公开范围待确认 |
| C | 仅作建模和灵感参考 | 未取得公开许可或包含敏感人物信息 |
| D | 不使用 | 权属不明、隐私风险、质量不可接受 |

## 每张素材登记字段

`assetId`、原始路径、地点 ID、拍摄者、拍摄日期、内容说明、可识别人物、可识别店铺/作品、授权等级、是否可裁切、是否可用于模型、事实来源、备注。

在授权结论未补齐前，所有包含店主、村民、调研成员的正脸照片、语音和可识别对白默认按 B 或 C 处理。首发人物形象统一采用风格化重绘；共同镜头使用“调研小队”群像，成员笔记分别按 `authorId` 管理；无录音素材，不制作语音内容。

## 对话重绘规则

店主、村民和畲族老师相关文字允许依据作者回忆与感悟进行创作化重写，但数据必须标记为 `field-note` 或 `creative`，不能使用“某某说：”加引号的逐字引用形式。实拍照片只作为证据层或素材对照，人物可识别时优先裁切至手部、背影、环境或做遮挡处理。
