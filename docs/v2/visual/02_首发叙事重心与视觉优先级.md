# 首发叙事重心与视觉优先级

> 状态：`approved-for-exploration`。本文件只调整首发视觉定稿的优先级，不将待授权或待整理内容提前写成公开正文。

## 首发重心

首发共八站；松庄的“村民参与艺术创作”线已确认成为第三站。视觉定稿与后续工程的优先级改为：

1. `SZ-02 诉土桌边`：与诉土店主的沟通、店内材料和调研成员观察。
2. `BQ-02 兰老师的现场讲述`：兰老师的现场讲述、编织观察与被谨慎组织的文化资料。
3. `YJ-02 屋脊白影`：让路趣事与成员感悟。
4. `SZ-03 手作的见证`：瓦片乌龟、木鸟与村民参与艺术创作的展板/作品证据。
5. 其余站点作为现场观察、趣事、证据或数字标本的节奏支撑。

物件在上述站中只承担开场、引导、转场或证据层功能。不得为了让观察者“有戏”而压过人与人的交流。

## SZ-02 诉土桌边

| 层级 | 内容角色 | 当前可用边界 |
| --- | --- | --- |
| 主要阅读 | 作者对与诉土店主沟通的回忆、店主希望更多文化交流的现场记录、成员对材料/村庄关系的感悟 | 店主相关文字按 `field-note` 或 `creative` 重写；不使用逐字引号，不替店主作社会结论 |
| 观察态 | 桌面、陶艺、小王子木雕、枯叶灯、材料痕迹与风格化店主剪影 | 实拍人物默认不作主图；以风格化重绘、手部/背影或已获许可素材呈现 |
| 观察者 | 陶土小猫仅作进入桌边与材料关系的引子 | 不替店主发言，不承担长篇台词 |
| 轻量趣事/摩擦 | 陶土小猫上的“文明参观”“损坏照价赔偿”提示，可引出外来者与空间规则的观察 | 不把提示写成对游客或村民的道德评判 |
| 待补 | 公开展示范围、作者希望公开的沟通细节、店主形象/作品的逐项授权 | 未确认前在网页中显示为待补或只保留抽象材料层 |

### 视觉定稿要求

- **观察态**：桌面与墙面材料形成温暖、具体的手作空间；陶土小猫只在边缘短暂停留。
- **阅读态**：对话纸带或田野旁注占据主要阅读位置，风格化店主剪影和手作局部提供陪衬。
- **不得生成**：无来源的“艺术村”装饰、完整店铺布局、虚构客人、虚构墙绘或未经确认的作品细节。

## BQ-02 兰老师的现场讲述

| 层级 | 内容角色 | 当前可用边界 |
| --- | --- | --- |
| 主要阅读 | 兰老师现场讲述的婚嫁、畲歌与布带片段，以及调研成员对当代变化的观察 | `oral-account`：标注“兰老师现场讲述，调研小队整理，辉记录”；不使用逐字引号，不外推为全部畲族地区的普遍事实 |
| 观察态 | 编织中的手、布带、线与经同意的风格化老师肖像/剪影 | 无录音，不制作拟真口述配音；人物实拍按授权和可识别性降级 |
| 观察者 | 布带只引导目光至手部和对话；头饰只作数字标本或证据层 | 不将头饰拟人化，也不让布带解释文化 |
| 资料层 | 头饰的照片所见轮廓、布带材质和 S2/S3 数字标本说明 | 材质、银饰结构、凤凰意象等未核验事项不能被生成图补写 |
| 待补 | 肖像与素材公开范围、可公开的口述整理文本、文化说明的逐条来源 | 未确认前不以正式文化说明发布 |

### 视觉定稿要求

- **观察态**：线、手部与布带的节奏建立近距离观看，老师形象保持风格化、克制和受尊重。
- **阅读态**：现场讲述整理是核心；旁注、来源状态和资料层可并置，但不将其做成民俗知识海报。
- **不得生成**：无来源畲族文字、泛化“民族风”图案、虚构仪式场面、蜂箱/桥梁等其他板桥站元素。

## 视觉制作顺序

```text
先确认 SZ-02 的可公开叙事单元与视觉边界
  -> 定稿 SZ-02 的观察态 + 阅读态（陶土小猫为引子）
  -> 确认 BQ-02 的口述整理与授权边界
  -> 定稿 BQ-02 的观察态 + 阅读态
  -> 用两站建立“人和现场观察为主、物件为引子”的全站模板
  -> 再推进其他五站
```

## 总控验收

- 视觉稿是否一眼看出“谁/什么交流或观察是本场景主要内容”？
- 拟人化物件是否能在五秒内退为引导，而不占据持续的阅读中心？
- 人物内容是否采用与来源、授权相匹配的表达方式？
- 没有文本时，场景是否仍以材料与关系成立；文本展开后，是否由对话/感悟而不是物件独白承担意义？
