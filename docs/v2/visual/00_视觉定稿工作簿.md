**1. 全局视觉合同**  
**已确认**  
- 作品类型：互动数字田野档案，不是完整村落跑图或传统游戏。  
- 统一语言：田野图鉴、民艺标本、纸质档案与低多边形/2.5D 舞台。  
- 画面事实：所有可识别的人、物、建筑、植物、纹样与空间关系均需有来源；缺失时留白或标明创作化。  
- 资产分层：生成图负责无 UI 场景和局部资产；代码负责 UI、文字、状态、交互和响应式布局。  
- 动效：以水、风、光、翻页、轻摆和观察者的轻微反应为主；可静态理解，且不能抢阅读。  
- 叙事优先级：人际对话、现场观察、调研成员感悟与趣事是主要阅读内容；观察者只作开场、引导、转场或趣事注释。文化资料、展板与数字标本仅在需要准确说明时居于主要位置。
