# 图像叙事起点说明

本轮采用 `Zeejay0/gathered-scenes-zine-skill` 的构图原则：照片保留事实，纸面抽象只提取照片中已经存在且能被核对的关系。图像不是正文，也不替代访谈；它负责让读者先认出材料、动作和空间，再进入文字。

## SZ-02 / 诉土桌边

- **素材来源**：`public/assets/images/songzhuang/sutuhu-worktable.jpg`。
- **图像先介绍什么**：夯土工作室、木工作台、陶土器物、画笔与枯叶灯共同托住一次交流；陶土小猫是桌边的入口线索。
- **纸面抽象做什么**：把工作台水平线、暖灯/陶土的暖色关系和器物密度压缩成大块，避免读者误认成完整店铺陈设。
- **文字随后承担什么**：调研成员与诉土店主的沟通摘要、店主明确允许公开的作品范围、现场观察与来源说明。未核验的具体对白、作品名称和完整陈设不从图像推断。

## BQ-02 / 兰老师的现场讲述

- **素材来源**：`public/assets/images/banqiao/lan-teacher-weaving.jpg`。
- **图像先介绍什么**：手指、木工具和蓝白织带的编织动作，红色衣物只作为现场色温背景。
- **纸面抽象做什么**：把织带的方向延展成一条蓝色结构线，帮助读者沿动作进入口述内容；不添加人物正脸或泛化畲族装饰。
- **文字随后承担什么**：兰老师可公开口述的分段、署名/整理方式、适用范围与调研成员的观察。纹样含义、婚俗结论和统计结论必须以报告或现场口述归属呈现。

## 其他站点的统一规则

每一张图先回答“读者能从授权素材中确认哪两个或三个元素”，再决定抽象关系。缺少照片或数据来源的元素留白；溪水、桃子、石拱桥只在 SZ-01 出现，木鸟与瓦片乌龟只在 SZ-03 出现，不能跨站复用。
