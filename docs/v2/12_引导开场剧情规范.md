# 引导开场剧情规范

## 叙事母题

**档案篝火夜话。** 地方观察者围坐在一团篝火意象旁，谈论最近来到村庄的一群“怪人”。“怪人”是物件对调研小队的调皮称呼：他们总会停下来、蹲下、抬头、摸摸石头、在水边停很久。

该篝火由板桥畲族乡三月三篝火晚会的意象启发，但它不是对现实仪式、时间、地点或参与者的复刻。页面和文案应明确把它作为跨村落的创作化档案空间。所有实际畲族文化说明仍须独立核验。

## 10 秒开场节奏

| 时间 | 画面 | 信息 |
| --- | --- | --- |
| 0-2 秒 | 墨青夜色与米纸颗粒中，一团温暖篝火亮起 | 建立夜话与档案感 |
| 2-5 秒 | 树根、屋脊白猫、溪中桃子、蜂箱、布带/头饰等观察者逐一进入火光边缘 | 物件是观察视角，不是装饰 |
| 5-7 秒 | 一个观察者以“最近来了一群怪人”开启话头；巫通儿在画面边缘短暂出现 | 建立调研组被观察的反转关系 |
| 7-9 秒 | 火星变成三个村落的档案印记 | 从创作框架过渡到真实地点 |
| 9-10 秒 | 标题、可跳过提示、三个村落入口出现 | 进入自由选择 |

## 文案边界

- 目前只确定“最近来了一群怪人”为剧情概念，不锁定完整对白。
- 后续台词由作者的回忆与感悟补写，数据状态先设为 `pending-author-note`。
- 具体人物、店主、村民不得被观察者代言；调皮评价只能针对调研小队的公开、非私密行为，且不把成员的个体行为误写成全队共同特征。
- 不使用未经核验的畲族语言文字、仪式解释或文化寓意作为开场装饰。

## 视觉边界

- 篝火使用暖橙、煤灰、纸纤维、木头和少量火星，不做大型节庆舞台或烟火秀。
- 观察者保持原物材质与比例感，只用克制的眼神、摇摆和靠近火光动作表达人格。
- 头饰与布带不应被拟人化为可供玩笑的道具；它们作为文化物件，以尊重的距离出现在火光与档案印记中。
