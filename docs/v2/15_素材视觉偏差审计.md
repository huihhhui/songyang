# 素材视觉偏差审计

更新时间：2026-07-22

## 问题结论

第二轮 AI 效果图与实地素材偏差较大，核心原因不是 API 或模型能力，而是生成流程没有把 `D:\codex_sy\sucai` 中的实拍素材作为强约束。

最明显错误：板桥畲族乡建筑被生成成了偏白墙、深木、泛化山村，而实拍素材明确显示其关键建筑语言是夯土黄泥墙、厚重乱石地基、旧木构、黑灰瓦和墙面装饰纹样。

## 直接原因

1. Prompt 写错了建筑材质。

   `tmp/imagegen/style-v2-calibration-prompts.jsonl` 中出现了 `white plaster`、`plaster white`、`white plaster and dark wood houses`。

   这会强烈诱导模型生成“白墙黑瓦”的通用江南/东亚古村印象，与板桥重点素材相冲突。

2. 生图没有使用实拍图片作为输入参考。

   之前只根据文字生成，没有把板桥 `1.jpg`、`2.jpg`、`3.jpg`、`4.jpg`、`6.jpg` 作为材质与结构参考图输入。因此模型只能根据“Songyang mountain village”自行补全。

3. 三村材质被混成了统一风格。

   杨家堂、松庄、板桥都有土墙、旧瓦、石路、木构，但差异不同：

   - 杨家堂：夯土黄、旧瓦灰、古樟深绿、石阶冷灰。
   - 松庄：斑驳白漆覆盖土墙、藤蔓旧瓦、溪水、艺术小物。
   - 板桥：夯土黄泥墙、乱石地基、万年青条状装饰、桥、蜂箱、畲族布带/头饰。

   生成时把它们压成了一个“泛化低多边形山村”，导致地方性被稀释。

4. “美术参考”没有转译成“素材优先规则”。

   参考风格只能决定低多边形、手工感、可爱化和展陈语气；建筑颜色、纹理、比例、特殊装饰必须服从实地素材。

## 后续修正规则

### 禁止项

- 禁止把板桥主建筑描述为 `white plaster houses`。
- 禁止默认使用“白墙黑瓦江南古村”作为松阳通用模板。
- 禁止只用风格游戏名或泛化关键词生成最终参考图。
- 禁止让 AI 自行添加不存在的牌匾、文字、宗教/民族符号。

### 必须项

- 板桥建筑主色：赭黄、蜂蜜土黄、灰褐土色，不是米白。
- 板桥墙体纹理：横向夯筑层、竖向裂缝、粗颗粒、小孔洞、泥土剥落。
- 板桥建筑结构：下部厚乱石地基，上部夯土黄泥墙，屋顶黑灰瓦，局部旧木构。
- 万年青图案作为板桥房屋立面细节，不能被省略或改成通用纹样。
- 三村分别建立材质表；生成某村效果图时只使用该村对应素材作为视觉锚点。

## 正确生成流程

1. 先选定村庄和观察站。
2. 从 `sucai` 中挑 3 到 6 张实拍参考图。
3. 明确每张图的角色：结构参考、材质参考、纹样参考、空间布局参考、物件参考。
4. 使用图片编辑/参考生成，而不是纯文本生成。
5. Prompt 中先写“必须来自参考图”，再写风格化要求。
6. 生成后与素材联系表对照，检查颜色、材质、结构、特殊符号。

## 板桥修正版视觉锚点

板桥不是白墙古村，而是以夯土黄泥房、乱石地基、旧木蜂箱、桥、古树、畲族布带与头饰构成的山乡场景。

适合的风格化方向：

- 几何形体简化。
- 材质色相保持真实。
- 纹理用手绘色块概括，不抹掉夯土颗粒。
- 让万年青纹样、石基厚度、泥墙裂缝成为识别点。
- 可爱化发生在观察者和动效上，不发生在建筑真实性上。
