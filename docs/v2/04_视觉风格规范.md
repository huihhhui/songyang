# 视觉风格规范

## 风格名称

田野图鉴、民艺标本与低多边形空间拼贴。

## 已确认的参考组合

| 层级 | 已选方向 | 用途 |
| --- | --- | --- |
| 主美术 | 民艺标本剧场 | 三维场景、观察者、木石瓦土与苔藓材质 |
| 叙事界面 | 田野影像日记 | 实拍证据、调研笔记、来源标记、对话内容 |
| 排版语言 | 纸艺档案拼贴 | 索引卡、照片裁切、趣事分镜、章节标签 |
| 村落总览 | 轻快几何山村 | 低多边形方位、漫游空间与观察站引导 |
| 数字标本 | 当代数字标本实验室 | 全屏模型、实拍对照、点云与数字化说明 |

不得把五种方向平均混合。首屏和观察站优先服从“民艺标本剧场”；界面内容优先服从“田野影像日记”。

## 四层画面

1. **空间层**：低多边形山村、坡地、石阶、房屋、树、水，负责方位与尺度。
2. **物件层**：带有手作感的观察者，负责情绪和注意力。
3. **证据层**：实拍照片、局部裁切、纹理、地点标记，负责可信度。
4. **档案层**：纸张、墨线、索引标签、来源状态，负责阅读秩序。

## 调色与材质

| 类别 | 色彩方向 | 材质关键词 |
| --- | --- | --- |
| 信息底 | 米纸白、旧页黄、墨青灰 | 纸纤维、印刷、批注 |
| 建筑 | 夯土黄、褪白灰、旧瓦灰 | 颗粒土墙、瓦片层叠、木纹 |
| 自然 | 樟树深绿、苔藓绿、溪水青绿 | 湿石、苔藓、叶影 |
| 强调 | 梅干菜暗红、纸灯暖黄、雕塑白 | 手作涂层、磨损、光晕 |

## UI 规则

- 知识卡像纸质索引卡，不使用玻璃拟态。
- 对话采用视觉小说底部纸带，不做普通居中弹窗。
- 照片质量不高时，使用局部裁切、证据条、接触印相式网格或半透明叠印，不做放大后的全屏背景。
- 不使用霓虹点云、大面积紫蓝渐变、无来源的复古纹理。
- 一屏只保留一个阅读重点；三维画面与文本不抢占同一焦点。

## 动效规则

环境镜头稳定，观察者动效克制。使用风、水、翻页、轻摆、光线变化提示生命感。点云只在数字标本页中用于“从实拍/模型浮现、散开、聚合”的解释性动效。
