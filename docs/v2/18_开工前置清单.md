# v2 开工前置清单

本清单将“可以先做”的结构工作与“公开发布前必须完成”的资料工作分开。未完成后者不阻塞原型，但阻塞公开发布。

## A. 可立即开工

- 旧 Demo 已弃用并移出项目；在干净的 `src/` 建立入口、路由、数据目录与七个观察站空壳。
- 实现档案总览、三村索引、自由进入、轻量建议路线、观察站、田野旁注、知识卡、数字标本实验室。
- 使用统一的调研小队风格化占位形象；每条成员旁注保留 `authorId`，但不要求成员素材到位。
- 以内部“田野笔记待补”占位测试版式；公开构建中自动隐藏这些条目。
- 为四件 S2 观察性数字标本准备模型槽位、实拍对照、来源状态与降级展示。

## B. 数据录入包

每位成员补充感想时，使用以下字段：

```text
authorId：稳定英文 ID，例如 hui
displayName：公开展示名或留空
stationId：对应观察站
body：第一人称正文
sourceStatus：field-note / oral-account / onsite-exhibit / public-source / creative
assetIds：支持该条的照片或展板编号
portraitConsent：placeholder / allowed / denied
displayScope：public / internal
reviewOwner：作者本人
```

## C. 素材与授权台账

- 每张实拍填写拍摄者、地点、对象、人物可识别性、店铺/作品、公开范围、裁切要求、建模许可。
- 松庄 `14.jpg`、`15.jpg`、`16.jpg` 逐字转写展板，并将转写稿与照片编号绑定。
- 店主、兰老师、村民、学生及调研小队照片在使用前分别确认肖像、作品与语境授权；不确定则只用不可识别裁切或风格化重绘。
- 原图保持在 `D:\codex_sy\sucai`；项目中只生成派生的网页副本、缩略图与优化版本。

## D. 四件数字标本输入

| 标本 | 最低准备 | 不能宣称 |
| --- | --- | --- |
| 杨家堂夫妻树局部 | 根、树洞、苔藓、石阶的多角度参考 | 完整古树测绘、树龄结论 |
| 板桥畲族头饰 | 正侧面、局部材质、布带关系、许可状态 | 扫描、原样复原、未核验寓意 |
| 板桥实体桥梁 | 正侧面、顶部、与环境比例 | 工程测绘、结构安全结论 |
| 板桥夯土黄泥房 | 正面、石基、立面装饰、材质近景 | 建筑测绘、保护政策结论 |

每件至少选定 3-8 张有用途说明的图片，模型按 S2 观察性建模。无法通过实拍对照或网页性能检查时，降级为图像档案。

## E. 音频选取与替换

- 需要四类短循环：全站背景、篝火、溪流、纸张/UI。
- 先使用具有明确可商用许可的候选素材；建立 `audio-manifest` 记录来源与许可证。
- 不使用无来源“民族风”作为畲族文化的代称；板桥章节采用与其他章节共享的整体配乐，环境声只承担空间感。
- AI 生成音频须记录模型/平台、生成日期、提示词版本、使用权条款，并在听感不适配时可单独替换，不影响页面逻辑。

## G. 发布门槛

公开构建前必须通过：构建、lint、主要流程截图检查、音频静音状态检查、素材授权台账检查、来源状态检查。任何 `pending-*`、`internal` 或无授权资产不得进入公开构建。
