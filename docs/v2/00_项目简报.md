# 项目简报

## 身份

- 项目名：《巫通儿：松阳寻踪》
- 建议副标题：被地方物件看见的田野笔记
- 项目类型：互动数字田野展览，不是传统游戏
- 当前项目根目录：`D:\codex_sy\wutonger-sunyang`
- 原始素材根目录：`D:\codex_sy\sucai`

## 核心命题

调研小组进入村庄后，树、水、器物、屋脊雕塑、店铺手作与空间如何“看见”他们。数字化服务于田野记录、地方叙事和可核验的展示，而不是用游戏任务替代调研。

## 已确定原则

1. 巫通儿是跨村落档案引路者，不是全部内容的讲述者。
2. 每个地点由一个具有真实出处的地方物件、自然物或手作物担任观察者。
3. 页面内容由数据驱动；地点正文、人物发言、图片说明不写死在组件内。
4. 内容必须区分现场观察、受访者转述、公开资料与创作化片段。
5. 点云或扫描效果只使用真实采集数据；数据不足时明确标注为观察性建模。

## 当前技术原型

现有 Demo 使用 React、Vite、Three.js 和 React Three Fiber，包含低多边形村落、巫通儿 GLB、基础漫游、碰撞、古树交互和研究卡片。它是技术资产，不是 v2 的最终页面架构。

## v2 交付目标

形成可浏览的村落档案：村落总览、观察站、观察者短场景、知识卡片、视觉小说对话、现场趣事和重点对象数字标本实验室。v2 不再尝试还原完整村落布局，也不设置自由漫游；每个观察站是基于已采证据建立的独立田野场景。

## 发布原则

采用混合发布。同一份静态构建产物必须可以在答辩现场通过本地启动器离线运行，也可以部署为在线静态站点供外部体验。运行时不依赖远程地图、CDN 字体、第三方接口或登录服务；所有必要图片、模型、文字与交互数据随构建产物提供。
