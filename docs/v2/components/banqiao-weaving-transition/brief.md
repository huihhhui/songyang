# 板桥编织转场组件

## 叙事作用

用户先理解“挑线—穿入—压紧”的动作，再看到松线如何进入畲族布带纹样，最后通过镜头右移进入兰老师的讲述页。

## 视觉层

- 底图：干净、低对比的米白织物/纸面。
- 左侧：代码控制的松线，仅负责交互反馈。
- 接缝：以用户定稿素材 `mid.png` 为源，网页使用去背景、去黑边和轻微同色校正后的 `mid-lines-web.png`，负责连接左侧可交互线与右侧布带。
- 右侧：以用户定稿素材 `right.png` 为源，网页使用裁出布带并轻微同色校正后的 `right-band-web.png`，避免整张纸面形成矩形色块。

## 禁止项

- 不再绘制假的竖向装饰线。
- 不出现与 `mid.png`、`right.png` 颜色和线位不一致的额外横线。
- 不让布带在推压阶段提前自己移动。
- 不把镜头右移实现成单独移动布带。

## 状态节奏

1. `pick`：竹片从左下向上挑起同色横线。
2. `weft`：竖线从上方贴着竹片穿入。
3. `push`：竹片向右，竖线被动受力并逐渐绷紧。
4. `rebound`：竹片微微回弹并短暂遮挡缝口。
5. `material-swap`：由竹片遮挡缝口，视觉上过渡到 `mid.png` 与 `right.png` 的自然连接。
6. `camera-shift`：镜头向右，整个场景向左，进入兰老师页面。
