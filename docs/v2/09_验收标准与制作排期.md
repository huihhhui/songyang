# 验收标准与制作排期

## 最小可演示版本

1. 档案总览能进入至少两个村落章节。
2. 每个章节至少有一个完整观察站。
3. 至少分别演示一次知识卡、对话/趣事和数字标本预览。
4. 用户可从任意层级返回上一级，不丢失当前位置。
5. 所有展示文字、图片和来源状态来自数据文件。
6. 缺失授权或扫描数据时，界面明确降级，不展示虚假内容。

## 已确认的体验与评审目标

- 核心体验：6-8 分钟，只经过三个村落的代表观察站。
- 完整体验：10-12 分钟，包含可选数字标本、证据照片与延伸阅读。
- 主评审目标：田野真实性与资料伦理；艺术叙事与视觉设计。
- 次评审目标：交互与三维技术；数字化展示。

主流程必须先让观众理解观察到的地方与人，再展示技术效果；模型、点云和交互不能替代资料来源说明。

## 质量验收

- 1366x768 与手机宽度下文本不溢出、不重叠。
- 键盘和鼠标均能完成主要导航；触摸设备能点击主要控件。
- 低质量照片未作为模糊全屏底图使用。
- 重点三维对象有清晰的尺度、来源和数字化等级说明。
- 构建通过，浏览器中验证首屏、章节、对话、实验室和返回流程。
