# 未决问题

本文件中的问题按影响范围排序。未确认前，后续实现必须采用可替换、可降级的结构，不得把任一选项硬编码为最终结论。

当前记录到 Q23 的产品级问题均已确认，没有阻塞工程基底制作的未决项。素材授权、成员旁注、模型和音频仍按发布门槛持续补齐。

## Q05 人物与对话授权

状态：已确认。

- 店主/村民照片：人物形象采用风格化重绘；实拍仅作证据层，人物可识别时裁切、遮挡或取得许可。
- 店主/村民文本：依据作者回忆与感悟写作，标记为 `field-note` 或 `creative`，不是逐字原话。
- 声音：无录制，首发不制作音频。
- 调研小队：共同镜头使用非可识别的风格化群像，不展示真实姓名；成员感想按独立作者 ID 与授权状态管理。
- 畲族老师、头饰、布带：人物形象风格化重绘；可使用实拍图作证据层。兰老师的现场讲述允许以 `oral-account` 公开转述，标注讲述者与整理者；未经核验的文化内涵不得作跨地区、跨群体的事实断言。

影响：视觉小说界面能否使用真人图像、原话与音频。

## Q11 引导开场剧情母题

状态：已确认。

采用“档案篝火夜话”。来自不同村落的拟人观察者围坐在篝火意象旁，聊起最近来到村庄的一群“怪人”（调研小队）；火星随后转化为三个村落入口。巫通儿只在画面边缘偶发出现。

该篝火是受板桥三月三篝火晚会意象启发的创作化跨村落档案空间，不复刻真实仪式，也不宣称三个村落的角色同处于现实时间地点。详细脚本见 `12_引导开场剧情规范.md`。

状态：已确认。

## Q18 感悟正文未完成时的开发占位策略

状态：已确认，采用 A。

大部分观察站正文仍待作者慢慢回忆与写作。开发阶段选择：A. 用显眼的“田野笔记待补”占位；B. 用 AI 自动补写为临时正文；C. 等全部正文完成后再制作页面。

开发阶段使用显眼的“田野笔记待补”内部占位，先完成数据结构、镜头、交互和视觉测试，同时避免把尚未发生的感悟误写成项目内容。正式发布前所有占位必须替换或隐藏。
