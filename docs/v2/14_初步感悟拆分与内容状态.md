# 初步感悟拆分与内容状态

> 来源：`D:\codex_sy\sucai\初步感悟和记录.txt`。整理日期：2026-07-23。
>
> 目的：把作者的现场感悟拆为可进入展览的数据单元，并把“田野观察”“待核验事实”“创作化演绎”严格分开。本文件不是对受访者的逐字访谈记录，也不是学术结论。

## 1. 使用规则

### 内容状态

| 标记 | 含义 | 首发网页可否展示 |
| --- | --- | --- |
| `field-note` | 作者亲历、感受或回忆性的转述 | 可，须标明“田野笔记/作者观察” |
| `oral-account` | 现场由具体讲述者口述、由作者转记的内容 | 可，须写明“现场口述整理”，不扩大为普遍事实 |
| `onsite-exhibit` | 现场展板、馆内说明等可追溯的陈列内容 | 可，须附展板照片或编号；不替代独立史实考证 |
| `creative` | 基于现场物件的艺术化演绎 | 可，须不伪装成事实或传说 |
| `verified-general` | 已由权威公开来源确认的一般背景 | 可，附来源链接 |
| `pending-verification` | 现有记录提及，但未取得可追溯的本地来源 | 不作为肯定事实写入正文 |
| `pending-report` | 需等小组专业调研报告后再提炼的结论 | 不进入首发正文 |
| `pending-author-note` | 需要作者补写的个人回忆与现场细节 | 可先作为内部占位，不公开 |

### 写作边界

1. 不把作者对老人、店主、司机、畲歌老师的印象写成带引号的“原话”。首发均使用无引号的概述，并标 `field-note`。
2. 不把一位受访者、一次偶遇或一处店铺的经验，扩大为“村民都……”“畲族人都……”的结论。
3. 白猫跳屋脊、瓦片乌龟进入溪流、物件夜话均属于 `creative`；它们可以富有生命感，但不能被包装成当地民间传说。
4. 板桥部分的民族历史、节庆、服饰、婚俗、学校与传承人信息，必须按“全国/区域一般背景”与“板桥现场事实”分别标注，不能互相替代。
5. 所有待核验的地方传说在上线前要么补来源，要么只保留为“听见的一则待考地方故事”，不提供事实性解释。

## 8. 需要作者逐项决定的戏剧内容

下面的问题不能由 AI 以“更有戏剧性”为由擅自补全。回答后即可把八站从骨架推进到正式分镜。

1. **明清古街与老人访谈**：以“辉的田野旁注”进入公开资料室；不进入 6-8 分钟主线。
2. **杨家堂门洞**：使用上午阳光、两位大妈拍照和主动让路的实际片段；不使用可识别脸部与对白。
3. **松庄红鲤鱼**：来自现场展板；下一步进行逐字转写并挂接照片证据。
4. **诉土的陶艺小猫**：获准公开；可在风格化重绘和资料室证据层中使用。
5. **畲歌老师形象**：允许使用经同意的风格化肖像。
6. **板桥婚俗信息**：来源为兰老师现场口述；以“现场讲述整理”呈现，不扩大为普遍民俗结论。
