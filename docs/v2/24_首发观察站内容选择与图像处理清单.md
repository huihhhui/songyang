# 首发观察站内容选择与图像处理清单

状态：`for-owner-review`。本表按观察站组织，不按素材文件夹或照片数量组织。正文在审核前只使用可核对的观察、口述整理和报告范围说明。

## 全站图像处理规则

- 所有公开照片保留原始文件、来源文件夹和公开状态；网页只引用其非破坏性展示版本。
- 统一处理为“档案印刷蒸馏”：裁切、有限色彩、纸张颗粒、低密度网点和滚动中的轻微位移。不得用处理效果增添、删去或重构可识别事物。
- 正文、来源、按钮和统计信息永远由 HTML 呈现，不烧录到图像中。
- 每站只选 1 张主图、1 至 2 张证据细节，图片负责停留与进入，文字负责对话、观察和研究结论。

## 两个完成样板的画面节奏

### SZ-02 诉土桌边

1. 灯下工作台先入场，标题和一句观察从其左侧浮出。
2. 读者滚动后，图像压缩为“材料证据”，交流摘要占据阅读中心。
3. 灯罩细节在段落末端作为停顿，而非新的故事主角。

### BQ-02 兰老师的现场讲述

1. 手部与布带的近景先入场，避免把人物面孔做成肖像海报。
2. 口述整理以连续阅读带展开，来源和适用范围随段落到达。
3. 编织细节收束页面，报告卡仅补充研究边界，不替代现场讲述。

## 后续动效准则

- 使用 CSS 的进入、裁切、颗粒呼吸和图文相对位移；`prefers-reduced-motion` 下全部静止且不影响阅读。
- 不用持续装饰性运动，不用自动播放音效；陶土小猫的音效在正式接入时必须由用户主动触发并可关闭。
- 动效只服务“看见 -> 停留 -> 阅读 -> 查来源”的次序，不承担事实或叙事结论。
